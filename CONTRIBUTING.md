# Contributing

Contributions are welcome. AI-assisted contributions are accepted under two rules.

## AI-assisted contributions

1. **Disclose AI use.** Every pull request or issue written with AI assistance must include an
   **AI Disclosure** section. Name the tool, say what it was used for, and say what you wrote or
   checked yourself. For example:

   > **AI Disclosure:** Code drafted with Claude Code, reviewed and modified by me. I ran the
   > tests and checked the change in the browser myself.

2. **Follow [good-oss-citizen](https://github.com/tesslio/good-oss-citizen).** AI contributions
   must follow its rules: read open issues and earlier pull requests first, keep one change per
   pull request with a minimal diff, run the tests, and have a human review everything before it
   is submitted. Install it in your fork before your agent starts work:

   ```sh
   tessl install tessl-labs/good-oss-citizen
   ```
